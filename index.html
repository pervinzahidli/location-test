🔒 Məlumatlandırma

Bot olmadiginizi təstiqləmək üçün location testini keçin

⚙️ İcazələri necə aktivləşdirmək olar?

Əgər Allow pəncərəsi açılmırsa, brauzer bu sayt üçün icazəni bloklamış ola bilər.

Android / Chrome:
Saytın ünvanının yanındakı işarəyə basın → Site settings → Location → Allow.

iPhone / Safari:
Safari-də sayt ayarlarını açın və Location icazələrini yoxlayın. Həmçinin telefonun Settings bölməsində Location Services aktiv olmalıdır.

İcazələri dəyişdikdən sonra bu səhifəyə qayıdıb yenidən yoxlayın.
